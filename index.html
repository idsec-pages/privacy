Privacy Policy

Last updated: October 24, 2026

This is a private, single-user application. It is not offered to the public and has no users other than its owner.

Data accessed

The application requests only the Google Drive drive.file scope. It can access only files and folders that it created itself, and cannot see, read or change any other files in the account.

How data is used

Files are stored in and removed from the owner's own Google Drive for the owner's own purposes only. No data is sold, shared with third parties, used for advertising, or used to train any model.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
